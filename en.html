01
MARKETPLACE

YouHelp

Online platform that connects families with verified nannies, babysitters, caregivers, tutors, and other household professionals. Users can browse specialist profiles, read reviews, publish job listings, and communicate directly with candidates. The service focuses on making it easier and safer to find reliable help for everyday family needs.

My Contribution

As a Full-Stack Developer, I worked across backend architecture, frontend development, and infrastructure, focusing on core marketplace functionality and codebase maintainability.

I contributed to migrating the legacy backend toward DDD and Clean Architecture using NestJS, TypeORM, and PostgreSQL. By improving domain separation and isolating data persistence through the Repository pattern, I helped reduce coupling and support reliable transactional workflows.

I developed core order management features, including order creation, provider matching, chat workflows, and a state machine enforcing business rules and valid order transitions. I also integrated payment gateway functionality to support secure transactions.

On the frontend, I introduced Feature-Sliced Design (FSD) and structured global state management with Redux Toolkit, improving code organization and component reuse across parent and babysitter dashboards. Migrating to Vite accelerated local development and Hot Module Replacement.

Beyond application development, I built a metrics microservice for aggregating technical and product data, configured GitHub Actions pipelines for automated testing and deployment, and introduced Docker Dev Containers, reducing developer environment setup from several days to minutes.

These contributions helped modernize legacy systems, strengthen order workflow reliability, and establish a more maintainable codebase while supporting faster feature delivery.

02
FINANCIAL RESEARCH PLATFORM

Channelchek

An investment research platform focused on small- and micro-cap companies. It provides investors with equity research, financial data, market news, company profiles, and executive interviews to help them evaluate emerging businesses and identify investment opportunities.

My Contribution

As a Full-Stack Developer, I built Channelchek from scratch, taking ownership of the platform's implementation across the frontend, backend, and data layers.

My responsibilities included setting up the Next.js application, developing reusable React components and pages with TypeScript, and implementing global state management with Redux Toolkit. I built the integration between the frontend and the WordPress CMS, developed GraphQL queries for retrieving content, and implemented backend functionality using PHP. I also worked with MySQL to support data storage and retrieval.

I was responsible for connecting these technologies into a unified application, implementing data flows between the frontend and backend, and ensuring that content managed through WordPress could be delivered to the user-facing platform. I established the project's core code structure and organized application logic to support maintainability and future development.

From the initial setup to the integration of the main application components, I implemented the platform's technical foundation, delivering a working financial research website designed to present company profiles, investment research, and market-related content.
